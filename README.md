# ExerciciosSO

Repositório com códigos autorais desenvolvidos para a disciplina de Sistemas Operacionais da Universidade Federal de São João del-Rei (UFSJ).

## 📁 Projetos

### 🧵 Condição de Corrida (Race Condition)
Código para análise de **corrida de threads**, utilizado para estudar e demonstrar **concorrência** e **condições de corrida** em sistemas operacionais.

- Tema: **concorrência entre threads**
- Objetivo: evidenciar como o acesso concorrente a recursos compartilhados, sem sincronização adequada, pode gerar **condições de corrida**

## 📌 Observações

Todos os códigos deste repositório são de autoria própria, desenvolvidos como trabalhos e atividades práticas da disciplina de Sistemas Operacionais cursada na **UFSJ**.
